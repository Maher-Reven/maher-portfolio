## What it is

The scroll X-ray on [Harness anatomy](/lab/harness-anatomy) shows how a request moves through layers. This panel lets you configure the harness — which tools are wired in, which autonomy tier is active — and run three fixed scenarios to see where the loop stops or escalates.

<HarnessBuilder />

Try **Read issue** on read-only with the issue reader enabled: it should complete. Flip to **Open pull request** on the same tier and watch permissions block the write. Enable **Payment API** and compare **Propose** versus **Gated automatic** — only the top tier clears the gate in this fiction.

<LeadershipNote>
  The interesting EM work is not picking the model — it is agreeing which tier each capability ships at before someone files the first incident. This toy panel is the conversation starter: "What would our log look like if payment were still on propose?"
</LeadershipNote>
